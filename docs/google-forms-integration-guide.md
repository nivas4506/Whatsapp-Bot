# Google Forms & Sheets Webhook Integration Guide

This guide walks you through setting up the Google Form, linking it to Google Sheets, and adding the Google Apps Script webhook trigger to automatically update your backend service (`POST /internal/forms/responses/sync`) when a student submits their formal request.

---

## Step 1: Create the Google Form

1. Go to [Google Forms](https://forms.google.com) and create a **Blank form**.
2. Set the Title: `Department Student Requirement Form (HOD Office)`.
3. Add the following questions (matching Section 8 of the PRD):

| Question Title | Question Type | Required? | Notes |
|---|---|---|---|
| **Reference Number** | Short answer | **Yes** | ⚠️ **Crucial**: This receives the code generated by the WhatsApp bot (e.g. `HOD-REQ-20260905-XXXX`). |
| **Student Full Name** | Short answer | Yes | Full student name. |
| **Register / Roll Number** | Short answer | Yes | Student university ID. |
| **Department & Semester** | Short answer or Dropdown | Yes | e.g. CSE - 5th Semester. |
| **Student WhatsApp Number** | Short answer | Yes | e.g. `+91 9876543210`. |
| **Request Category** | Dropdown | Yes | Certificates, Attendance, Leave, Exam Issue, Project/Internship, Complaint, Appointment. |
| **Brief Title / Subject** | Short answer | Yes | Short summary of requirement. |
| **Detailed Requirement** | Paragraph | Yes | Detailed description. |
| **Supporting Document** | File upload | Optional | Medical certificate, offer letter, or ID card. |
| **Declaration & Consent** | Checkboxes | Yes | "I confirm the above details are accurate." |

---

## Step 2: Link Google Form to a Google Sheet

1. In your Google Form editor, click on the **Responses** tab at the top.
2. Click **Link to Sheets** (the green spreadsheet icon) or **"Select destination for responses"**.
3. Choose **"Create a new spreadsheet"** (e.g. `HOD Student Requirements - Responses`) and click **Create**.
4. The Google Sheet will open in a new tab.

---

## Step 3: Open Google Apps Script

1. Inside the newly opened Google Sheet, click the top menu:
   **Extensions** > **Apps Script**.
2. A code editor will open. Rename the project from `Untitled project` to `HOD Helpdesk Webhook`.
3. Delete any default placeholder code inside `Code.gs`.

---

## Step 4: Paste the Webhook Script

Copy the code from [`scripts/google-apps-script/Code.gs`](../scripts/google-apps-script/Code.gs) and paste it into the editor:

```javascript
var BACKEND_BASE_URL = "https://<YOUR-BACKEND-DOMAIN>"; // Replace with your backend URL
var SYNC_ENDPOINT = BACKEND_BASE_URL + "/internal/forms/responses/sync";

function onFormSubmit(e) {
  try {
    var referenceId = "";
    var formResponseId = "";

    // 1. Extract Reference ID
    if (e && e.namedValues) {
      var possibleFieldNames = [
        "Reference Number",
        "Case Reference",
        "Reference ID",
        "Tracking Reference"
      ];
      for (var i = 0; i < possibleFieldNames.length; i++) {
        var key = possibleFieldNames[i];
        if (e.namedValues[key] && e.namedValues[key][0]) {
          referenceId = e.namedValues[key][0].trim();
          break;
        }
      }
    }

    // 2. Extract unique response identifier
    var row = e && e.range ? e.range.getRow() : new Date().getTime();
    formResponseId = "GF-RESP-" + new Date().getTime() + "-R" + row;

    if (!referenceId) {
      Logger.log("No reference ID found in submission.");
      return;
    }

    // 3. Send Webhook to Backend
    var payload = {
      referenceId: referenceId,
      formResponseId: formResponseId
    };

    var options = {
      method: "post",
      contentType: "application/json",
      payload: JSON.stringify(payload),
      muteHttpExceptions: true
    };

    var response = UrlFetchApp.fetch(SYNC_ENDPOINT, options);
    Logger.log("Response: " + response.getResponseCode() + " " + response.getContentText());
  } catch (error) {
    Logger.log("Exception in onFormSubmit: " + error.toString());
  }
}
```

> **Important**: Replace `https://<YOUR-BACKEND-DOMAIN>` with your live backend domain (or your `ngrok`/`cloudflared` HTTPS tunnel URL if testing locally).

Click the **Save** disk icon (or press `Ctrl + S`).

## Step 5: Configure the Automated Trigger

1. In the Apps Script left sidebar, click the **Triggers** icon (looks like an alarm clock ⏰).
2. Click the blue **+ Add Trigger** button (at the bottom right).
3. Set the trigger fields as follows:
   - **Choose which function to run**: `onFormSubmit`
   - **Choose which deployment should run**: `Head`
   - **Select event source**: `From spreadsheet`
   - **Select event type**: `On form submit`
   - **Failure notification settings**: `Notify me daily` (or immediately)
4. Click **Save**.
5. Google will prompt you to **Review Permissions**:
   - Choose your Google account.
   - Click **Advanced** > **Go to HOD Helpdesk Webhook (unsafe)**.
   - Click **Allow** (this grants permission for the script to make external HTTP requests via `UrlFetchApp`).

---

## Step 6: Test the Integration End-to-End

1. Start your local server or Docker container:
   ```bash
   npm run dev
   # OR
   docker-compose up -d
   ```
2. Open your WhatsApp Simulator (`npm run simulator`) and send a formal request:
   - Input: `"I need a bonafide certificate for my passport"`
   - The bot will generate a tracking reference like: `HOD-REQ-20260905-XXXX`.
3. Open your Google Form in a browser:
   - Paste that reference number into the **Reference Number** field.
   - Fill in sample details and click **Submit**.
4. Check your server logs:
   - You will see:
     ```
     [Form Sync] Linked Form Response GF-RESP-... to Ref HOD-REQ-20260905-XXXX
     ```
5. Verify via API:
   ```bash
   curl http://localhost:3000/internal/requirements/HOD-REQ-20260905-XXXX
   ```
   The requirement status will now be updated to **`SUBMITTED`** with the attached `formResponseId`!

## Pro Tip: Pre-filled Form Links

You can configure Google Forms to automatically pre-fill the **Reference Number** so the student doesn't even need to type it!

1. In Google Form, click the three dots icon (`⋮`) in the upper-right corner.
2. Click **"Get pre-filled link"**.
3. Type `REFERENCE_PLACEHOLDER` in the Reference Number field.
4. Click **"Get link"** and copy it.
5. The URL will look like:
   `https://docs.google.com/forms/d/e/.../viewform?usp=pp_url&entry.123456789=REFERENCE_PLACEHOLDER`
6. You can replace `REFERENCE_PLACEHOLDER` with `${req.referenceId}` in your bot's response message so the link opens with their reference number already filled in!
